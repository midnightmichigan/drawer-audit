The safety advice for loose button-battery doors is "put tape over it." This kit is the real fix.

Remotes, flameless candles, key fobs, kitchen scales, musical greeting cards — dozens of devices in your home run on button batteries behind doors that pop open with a fingernail. The Drawer Audit retrofit kit secures those compartments so they need a tool to open. One kit, one 15-minute room-by-room audit, every device you already own.

The design rule: every secured compartment must require a tool to open. If a component can't achieve that on a device type, the checklist says so honestly and routes that device to "store out of reach" instead. No component damages the device or blocks its function — IR windows on remotes stay clear.

Plain-language honesty: this kit secures compartments so they need a tool to open. It does not make any device "childproof," and it is a supplement to — never a replacement for — safe storage and supervision. A swallowed button battery is a medical emergency; if that ever happens, call emergency services first, not us.
